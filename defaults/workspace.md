# Multi-repository workspace routing

This directory is a workspace container. Resolve the requested repository and its
actual worktree before editing or using repository-aware tools. Read that project's
applicable instructions; do not route unrelated projects through Smart Example.
Use the personal `sdd-workflow` default when no project workflow supplies the route.

For multi-repository work, identify each checkout, relevant revision, write scope
and owner. Preserve unrelated work and avoid concurrent writers to the same scope.
Use exact repository paths for indexed tools; qualify missing/stale indexes rather
than claiming text search is semantic evidence. Delegation and index creation
follow current task authority and actual need, not a mandatory bootstrap step.
