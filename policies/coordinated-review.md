# Coordinated review policy

Use only when applicable instructions select this policy and multiple reviewers are explicitly authorized. It never authorizes delegation or requires it for ordinary work.


When multiple reviewers are assigned, all review the same frozen semantic
snapshot. Every inventory/recheck reviewer is read-only and no agent edits until
all reviews return. A required reviewer-authored test is returned as an exact
finding/test contract; one designated writer authors the complete test group in
the subsequent correction iteration, unless isolated disjoint worktrees were
explicitly assigned. Return the whole P0-P3 inventory once; then the owner
deduplicates and applies one correction batch. Recheck the corrected snapshot read-only. If material findings remain,
return them to the authorized correction owner and continue useful iterations;
do not impose a fixed review count or repeat an unchanged attempt. Batch source-identity updates at useful verification or handoff boundaries;
keep evidence current at meaningful boundaries.
