## ADDED Requirements

### Requirement: Conditional portable guidance
The shared workflow SHALL provide reusable testing, review, Go and Rust guidance through conditional references in existing skills, without requiring unrelated language or specialist reading.
#### Scenario: Applicable engineering question
- **WHEN** an adopted repository needs test-boundary, isolation, concurrency or language guidance
- **THEN** its pinned shared source supplies the relevant procedure without Smart Example product assumptions
#### Scenario: Routine text change
- **WHEN** a routine text edit has no behavior or specialist risk
- **THEN** no language reference or testing campaign is required merely by discovery

### Requirement: Preserved consumer contracts
Extraction SHALL keep exact product contracts, commands, authority and campaign acceptance in consumer adapters. A reviewer within authorized implementation SHALL return to repair and affected revalidation in the same change; review-only scope SHALL remain read-only.
#### Scenario: Existing consumer
- **WHEN** reusable guidance is extracted from a consumer
- **THEN** existing entrypoints resolve a single canonical body and retain local error, signing, test and protected-operation constraints
#### Scenario: Missing reference
- **WHEN** a required packaged reference is missing
- **THEN** reference validation fails instead of accepting the broken route
