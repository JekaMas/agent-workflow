# Proposal
## Why
Remaining general debugging, conflict, maintenance and validation procedures are still embedded in a consumer, and existing-repository adoption requires manual wiring.
## What Changes
- Extract general skills, maintenance and validation mechanisms; retain product policy in adapters.
- Detect module roots for new adopters and offer fingerprint-bound reviewed migration for existing setups.
- Document one installation/update path and a shared responsibility map.
## Capabilities
### New Capabilities
- `unified-adoption`: reusable procedure distribution and safe low-friction adoption.
### Modified Capabilities
- `portable-workflow`: add an explicit fingerprint-bound reviewed migration exception; preserve ordinary collision refusal.
## Impact
Shared/consumer workflow source and local fixtures only; no product changes, tool installations, hosted calls or CI extensions.
