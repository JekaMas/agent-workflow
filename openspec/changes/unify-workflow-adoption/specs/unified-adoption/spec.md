## ADDED Requirements
### Requirement: General procedures have shared owners
The package SHALL distribute conditional debugging, conflict resolution, engineering evidence and knowledge maintenance without consumer product assumptions. Consumer adapters SHALL retain domain contracts and authority.
#### Scenario: Authorized repair
- **WHEN** debugging identifies an in-scope cause during implementation
- **THEN** repair and revalidation continue in the same change without a separate-role handoff
#### Scenario: Diagnosis only
- **WHEN** the request excludes edits
- **THEN** the same skill reports evidence and proposed experiments without applying repairs
### Requirement: Simple safe adoption
Bootstrap SHALL propose language routes from actual manifests when no explicit profile exists and SHALL preserve existing project instructions and active specifications. Existing setup replacement SHALL require an explicitly selected reviewed plan bound to previous and proposed file identities and source revision.
#### Scenario: Stale reviewed plan
- **WHEN** an affected file, profile or selected source changes after preparation
- **THEN** adoption refuses before mutation
#### Scenario: Existing active change
- **WHEN** reviewed workflow integration is adopted around an existing OpenSpec change
- **THEN** its specs, design, tasks and evidence remain byte-identical
### Requirement: Local policy stays explicit
Reusable publication and skill validators SHALL accept consumer inventory and packaging policy without imposing Smart Example defaults on new repositories.
#### Scenario: Consumer policy violation
- **WHEN** a selected local policy or required source is violated
- **THEN** validation returns failure without changing permissions or silently dropping the check
