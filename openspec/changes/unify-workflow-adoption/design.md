# Design

Shared source owns general procedures and validator algorithms; consumer JSON selects publication roots and packaging policy. Existing names remain thin adapters so domain routes survive. Fixed consumer budgets, flat-reference and implicit-invocation policies do not become universal defaults.

Bootstrap detects checked-in/on-disk Go and Rust module manifests while excluding vendor/build/shared trees and following no links. Detection is a proposal, never toolchain qualification or product command execution. Explicit profiles win. Existing OpenSpec setups require a prepared migration plan binding prior files, proposed outputs, repository and source revision; inspect custom config/instructions before applying. Only listed outputs change. Active specs/changes are preserved; no force bypass or framework reinstall.

Validate new/managed/custom adopters, stale-plan rejection, unchanged custom artifacts, missing references, publication failures and both client routes. Existing product approvals remain local. Evidence and coverage belong here, not another consumer task list.
